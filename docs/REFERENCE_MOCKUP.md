File:

```text
reference/stack-ui-reference.png
```

## What the mockup controls

- Overall visual tone
- Dark-only direction
- Screen hierarchy
- Three-tab navigation
- Race summary
- Manual completion form
- Lightly dimensional block treatment
- Plan-row density
- Accent palette

## What the mockup does not control

- Exact dates shown in the generated artwork
- Exact metric values
- Exact text wrapping
- Phone-frame chrome
- Any accidental inconsistency created by image generation
- A requirement for 3D rendering
- A requirement to place blocks manually
- A requirement to show gray rest blocks

## Implementation interpretation

Use the mockup as a visual target, then follow the repository specs where it conflicts.

The actual Build screen:

- Uses 18 centered week rows.
- Uses non-rest workouts only.
- Reveals predetermined blocks.
- Uses CSS depth, not perspective.
